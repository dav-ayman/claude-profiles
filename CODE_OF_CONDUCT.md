# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, keep feedback about the work, and make everyone feel welcome whatever their background or experience.

Report unacceptable behavior privately through [GitHub security advisories](https://github.com/dav-ayman/claude-profiles/security/advisories/new) or by messaging the maintainer, [@dav-ayman](https://github.com/dav-ayman). Reports are handled confidentially.
